# Claude 使用指南 2026

靜態網站，整理 2026 年最新的 Claude 使用方法與實用技巧。首頁為總覽，`guides/` 下有 8 個繁體中文分頁（官方資源與實戰文章的中文整理，各頁底部附原始出處）：

- **模型家族**：Claude 5（Fable / Mythos）、Opus 4.8、Sonnet 4.6、Haiku 4.5
- **使用入口**：Claude.ai、Claude Code、Claude API
- **核心功能**：Projects、Artifacts、Research、Claude Design、連接器
- **提示詞技巧**：7 個經過驗證的 prompt 寫法
- **Claude Code**：常用指令、Plan Mode、上下文管理、CLAUDE.md
- **進階技巧**：Hooks、Skills、Subagents、MCP

## 本地預覽

直接用瀏覽器打開 `index.html` 即可，無需建置步驟。
