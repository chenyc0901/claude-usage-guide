開始使用 Claude.ai：新手入門

從註冊到第一次對話，這篇帶你把 Claude 用起來。不需要任何技術背景。

1. 註冊帳號

到 claude.ai，用 Google 帳號或 Email 註冊即可，免費方案不需要信用卡。註冊後可以直接在網頁使用，也可以下載：

  • 手機 App：iOS（App Store）與 Android（Google Play）都有官方 App，支援語音對話與拍照提問。
  • 桌面 App：Mac 與 Windows 版本，支援全域快捷鍵，隨時呼叫 Claude。

2. 方案比較

方案適合誰重點
Free想先體驗的人每日有用量限制，可使用基本功能
Pro日常重度使用者更高用量、Projects、進階模型、Research 功能、Claude Code 基本用量
Max專業工作者、開發者Pro 的數倍用量，分兩個級距，適合整天掛著 Claude Code 工作的人
Team / Enterprise團隊與企業集中帳務、管理功能、更高的資料安全保證

價格會隨時間調整，請以 官方定價頁 為準。一般建議：先用 Free 體驗，覺得有價值再升 Pro；如果 Claude Code 用量常常見底，再考慮 Max。

3. 介面導覽

  • 對話框：直接打字提問。可以拖放檔案（PDF、Word、Excel、圖片）進來一起分析。
  • 模型選擇器：對話框附近可切換模型。日常任務用預設即可；複雜推理或長時間任務選最強模型（付費方案）。
  • Projects：左側欄建立專案，上傳背景資料、設定自訂指示，之後該專案內的每次對話都自帶這些脈絡。
  • Artifacts：請 Claude 做網頁、簡報、文件時，成品會出現在右側視窗，可即時預覽、修改、發布分享。
  • 連接器（Connectors）：在設定中連接 Google Drive、Notion、行事曆等服務，讓 Claude 直接讀你的資料工作。

4. 第一次對話的建議

  1. 講清楚背景和目的：「幫我寫一封給客戶的英文道歉信，因為出貨延遲一週，語氣誠懇但不卑微」比「寫封信」好太多。
  2. 把它當對話，不是搜尋引擎：第一次結果不滿意，直接說哪裡要改，Claude 會記得前文持續修正。
  3. 大膽丟檔案：上百頁的 PDF、整份 Excel 都可以直接丟進去問問題。
  4. 要求最新資訊時開啟搜尋：問時事、價格、新聞時，Claude 會自動搜尋網路；做深度調查時可用 Research 功能，產出帶引用來源的報告。
💡 小提醒：Claude 可能會出錯（尤其是具體數字、文獻引用）。重要決策前，請自行驗證關鍵事實。
