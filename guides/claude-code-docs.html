Claude Code 安裝與功能總覽

Claude Code 是在你電腦上運作的 AI 編程代理（coding agent）——它能讀寫檔案、執行指令、操作 Git，自主完成完整的開發任務，而不只是給建議。

1. 安裝

# 方式一：npm（需 Node.js 18+）
npm install -g @anthropic-ai/claude-code

# 方式二：原生安裝（macOS / Linux）
curl -fsSL https://claude.ai/install.sh | bash

# 啟動：在專案資料夾執行
cd 你的專案
claude

第一次啟動會引導你登入（用 Claude.ai 訂閱帳號或 API key 皆可）。除了終端機，Claude Code 也有 桌面 App（Mac／Windows）、網頁版（claude.ai/code）與 IDE 擴充（VS Code、JetBrains），登入同一帳號即可共用設定。

2. 基本操作模式

  • 直接交辦任務：用自然語言描述要做的事，例如「幫我修掉登入頁面的 bug，重現步驟是……」。Claude 會自己探索程式碼、修改、執行測試。
  • Plan Mode：按 Shift+Tab 切換。在這個模式下 Claude 只會研究和提出計畫、不動手改任何檔案，等你確認後再執行。複雜任務強烈建議先走這一步。
  • 權限模式：預設每個有風險的動作（執行指令、改檔案）都會先問你；信任後可以調整為自動接受編輯，加快流程。

3. 常用指令與快捷鍵

指令功能
/init掃描專案、自動產生 CLAUDE.md 專案說明文件
/config開啟設定（回應風格、主題、模型等）
/compact壓縮對話歷史，釋放上下文（context）空間
/clear清空對話，開始全新任務
/mcp管理與驗證 MCP 伺服器
/doctor檢查安裝與環境問題
/help列出所有可用指令
Shift+Tab切換 Plan Mode 與自動接受模式
Esc隨時打斷 Claude；連按兩下可回到歷史訊息重新編輯
@檔名在訊息中精準引用特定檔案
!指令直接執行 shell 指令，輸出會進入對話脈絡

4. CLAUDE.md：給 Claude 的專案手冊

放在專案根目錄的 CLAUDE.md 會在每次啟動時自動載入，等於給 Claude 的「新人手冊」。建議記錄：

  • 建置與測試指令（npm run build、pytest 等）
  • 程式碼風格與命名慣例
  • 專案架構重點、不能碰的地方
  • 常見地雷與注意事項

另外有 ~/.claude/CLAUDE.md（全域、所有專案都載入）可放個人偏好。保持精簡——它佔用每次對話的上下文。

5. 設定與擴充

  • settings.json：.claude/settings.json（專案）與 ~/.claude/settings.json（全域），管理權限白名單、環境變數、hooks。
  • MCP（Model Context Protocol）：連接外部工具——資料庫、瀏覽器、Slack、內部 API。用 claude mcp add 或 /mcp 管理，生態系已有數千個現成伺服器。
  • Skills 與 Subagents：可重用工作流與平行子代理，詳見進階篇。
