01認識 Claude 模型家族

2026 年 Anthropic 推出了全新的 Claude 5 家族，並持續更新 4.x 系列。選對模型是用好 Claude 的第一步。

模型定位適合場景
Claude Fable 5 最新 Claude 5 家族首發，全新 Mythos 級模型，能力高於 Opus，為目前公開可用的最強模型 最複雜的推理、代理任務、長時間自主工作
Claude Mythos 5 與 Fable 5 同底層模型，僅開放給通過審核的組織 特定企業與研究用途
Claude Opus 4.8 2026 年 5 月發布，代理編碼、電腦操作、財務分析大幅提升 日常重度開發、複雜分析
Claude Sonnet 4.6 性價比主力，價格較上代大幅調降 大多數日常任務、產品整合
Claude Haiku 4.5 最快、最便宜 即時回應、大量批次處理、簡單分類

2026 年模型層面的重要更新

NEW

Adaptive Thinking 自適應思考

取代過去的 Extended Thinking。模型會依任務難度自動決定要不要深度推理，不再需要手動設定思考預算。

NEW

100 萬 Token 上下文

Opus 4.6 與 Sonnet 4.6 的 1M token 長上下文已納入標準定價，可一次塞進整個程式碼庫或數百頁文件。

省錢

價格大幅調降

旗艦模型 API 價格降至 $5 / $25（每百萬 token 輸入/輸出），比上一代便宜約 67%，重度使用更划算。

02三種使用入口

依照你的身分和需求，選擇最適合的方式開始。

🌐 Claude.ai（一般使用者）

網頁版、手機 App（iOS / Android）、桌面 App。免費方案即可體驗，Pro / Max 方案解鎖更高用量與最強模型。直接到 claude.ai 註冊即可。

⌨️ Claude Code（開發者）

在終端機、桌面 App、IDE（VS Code / JetBrains）或網頁中運作的 AI 編程代理，能讀寫檔案、執行指令、操作 Git，自主完成完整開發任務。

🔌 Claude API（建構產品）

透過 Anthropic API 把 Claude 整合到自己的應用，支援工具呼叫、串流、提示快取、批次處理與 MCP，也可經 AWS Bedrock、Google Vertex 使用。

# 安裝 Claude Code（需 Node.js 18+）
npm install -g @anthropic-ai/claude-code

# 在專案資料夾啟動
cd 你的專案 && claude

03Claude.ai 核心功能

這些功能讓 Claude 不只是聊天機器人，而是完整的工作平台。

必學

Projects 專案

為長期工作建立專案，上傳背景資料當作知識庫，並設定自訂指示。之後每次對話 Claude 都記得這些脈絡，不用重複貼上。

必學

Artifacts 即時產出

請 Claude 做網頁、簡報、文件、互動小工具時，成品會在側邊視窗即時呈現，可以直接預覽、迭代修改，甚至發布分享給別人使用。

網頁搜尋與深入研究

Claude 可以即時搜尋網路取得最新資訊；Research 功能會自動進行多輪搜尋與交叉比對，產出有引用來源的完整研究報告。

檔案與圖片理解

直接拖放 PDF、Word、Excel、CSV、圖片進對話。Claude 能讀懂數百頁文件、分析表格資料、解讀圖表與截圖。

NEW

Claude Design

2026 年 4 月由 Anthropic Labs 推出，可與 Claude 協作生成設計稿、原型與簡報等視覺作品。

連接器（Connectors / MCP）

把 Google Drive、Notion、行事曆等服務接進 Claude，讓它直接讀取你的文件和資料來工作，不必手動複製貼上。

04提示詞（Prompt）技巧

同樣的問題，問法不同，結果天差地遠。這些是官方文件與社群驗證過最有效的技巧。

1

明確、具體、給足脈絡

把 Claude 當成「能力很強但不了解你背景的新同事」。說清楚目的、對象、限制條件。
❌「幫我寫一封信」 → ✅「幫我寫一封給房東的中文信，語氣禮貌但堅定，要求修理漏水的窗戶，提到已反映過兩次」。

2

給範例（Few-shot）

想要特定格式或風格時，直接給 1–3 個理想範例，比用文字描述有效得多。例如要整理資料時，先示範一筆你想要的輸出格式。

3

用結構化標籤分隔內容

長提示中用 XML 標籤把不同部分隔開，Claude 對這種結構特別敏銳：<文件>...</文件>、<指示>...</指示>、<範例>...</範例>。

4

長資料在前，指令在後

處理長文件時，把文件內容放在提示的前面，你的問題和指令放在最後面，準確度會明顯提升。

5

指定角色與輸出格式

「你是一位資深的稅務會計師」這類角色設定能有效提升專業度；同時明確指定要表格、條列還是特定字數的段落。

6

允許它說「不知道」

加上「如果你不確定，請直接說不確定」可大幅減少幻覺（編造內容），在查核事實、引用文獻時特別重要。

7

迭代修正，而不是砍掉重練

第一次結果不滿意時，具體指出哪裡要改（「第二段太正式，改口語一點」），通常兩三輪就能收斂到理想結果。

05Claude Code 使用方法

Claude Code 是開發者最強的生產力工具——它不只給建議，而是直接在你的專案中動手完成工作。

常用指令速查

指令功能
/init掃描專案並產生 CLAUDE.md 專案說明文件
/config調整設定，包含回應風格（簡潔／詳細／技術）
/mcp管理與驗證 MCP 伺服器連線
/compact壓縮對話歷史，釋放上下文空間
/doctor檢查安裝與環境問題
Shift+Tab切換 Plan Mode（先規劃、不動手）與自動模式
Esc隨時打斷 Claude，修正方向

👉 想看全部指令？Slash 指令完整參考——按用途分類整理每個指令的用法，含自訂指令教學。

核心工作流

最重要

先規劃，再執行（Plan Mode）

複雜任務先用 Plan Mode 讓 Claude 提出完整方案，你確認方向沒錯再放行。修正一份計畫，遠比收拾寫到一半的錯誤程式容易。

最重要

管理上下文（Context）

上下文是最珍貴的資源。用量到 90% 時輸出品質會明顯下降——適時用 /compact 壓縮，或開新對話、把長期知識寫進 CLAUDE.md。

寫好 CLAUDE.md

放在專案根目錄，記錄建置指令、程式風格、測試方式、注意事項。每次啟動自動載入，等於給 Claude 的「新人手冊」。

要求提出證據

別讓 Claude 只說「完成了」——要求附上測試輸出、執行的指令與結果、或畫面截圖。看證據比自己重跑驗證快得多。

06進階技巧：Hooks、Skills、Subagents

2026 年的 Claude Code 已是完整的代理平台，這些功能讓它從「助手」升級為「可靠的自動化系統」。

進階

Hooks：100% 確定性的自動化

在工具呼叫前後自動執行 shell 腳本。「每次改完檔案要跑 formatter」「禁止碰 production 設定」這類絕對不能漏的規則，做成 hook 而不是用嘴巴提醒。

進階

Skills：可重用的工作流

把你調教好的流程存成 Skill，之後情境符合時 Claude 會自動套用，不必每次重新解釋你的偏好和標準。

進階

Subagents 子代理

把搜尋、研究等支線任務派給子代理平行處理，保護主對話的上下文。搭配 Dynamic Workflows 可讓大型任務由數百個平行子代理協作完成。

進階

MCP：連接萬物

Model Context Protocol 讓 Claude 連上資料庫、瀏覽器、Slack、內部 API 等外部系統。用 /mcp 管理，生態系已有數千個現成伺服器。

💡 心法總結：把 Claude 當成有能力但需要好情報的隊友——給足脈絡、先對齊計畫、守住上下文品質、用 hooks 把鐵律自動化、用證據驗收成果。做到這五點，就超越了 90% 的使用者。
